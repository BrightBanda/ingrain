# Auto-Fetch YouTube Transcript & Duration Plan

## Goal
When user adds YouTube content, automatically fetch video duration and transcript (captions) using `youtube_explode_dart`, pre-fill the transcript editor for review, with manual fallback if auto-fetch fails.

## Decisions Made
- **Fetch method**: `youtube_explode_dart` (no API key, gets metadata + captions)
- **Fetch timing**: Before navigation, in `ContentAddView` (show loading on submit)
- **Success behavior**: Pre-fill `TranscriptEditorView` with fetched data, let user review/edit

### 2. Create YoutubeTranscriptFetcher Service
```dart
// lib/features/content/data/youtube_transcript_fetcher.dart
class YoutubeTranscriptFetcher {
  final YoutubeExplode _youtubeExplode = YoutubeExplode();

  Future<YoutubeTranscriptResult> fetch(String videoId) async {
    // Get video metadata (duration)
    final video = await _youtubeExplode.videos.get(videoId);
    final duration = video.duration?.inSeconds ?? 0;

    // Get captions (try manual first, then auto-generated)
    final manifest = await _youtubeExplode.videos.closedCaptions.getManifest(videoId);
    final track = manifest
        .where((t) => t.kind == ClosedCaptionKind.standard)
        .firstOrNull
      ?? manifest
        .where((t) => t.kind == ClosedCaptionKind.autoGenerated)
        .firstOrNull;

    String? transcriptText;
    if (track != null) {
      final captions = await _youtubeExplode.videos.closedCaptions.get(track);
      transcriptText = _captionsToText(captions);
    }

    return YoutubeTranscriptResult(
      durationSeconds: duration,
      transcriptText: transcriptText,
      hasAutoGenerated: track?.kind == ClosedCaptionKind.autoGenerated,
    );
  }

  String _captionsToText(ClosedCaptionTrack captions) {
    // Convert to SRT-like format for TranscriptParser
    return captions.captions
        .map((c) => '${_formatTime(c.start)} --> ${_formatTime(c.end)}\n${c.text}')
        .join('\n\n');
  }

  String _formatTime(Duration d) => ...; // HH:MM:SS,mmm
}
```

### 4. Update ContentAddView
- Add `_isFetching` state
- On submit:
  1. Parse video ID
  2. Set `_isFetching = true`
  3. Call `YoutubeTranscriptFetcher.fetch(videoId)`
  4. On success: navigate to `/content/:id/transcript` with pre-filled data
  5. On failure: navigate to editor with empty state (current behavior)
  6. Always reset `_isFetching` in `finally`

### 5. Update TranscriptEditorView
- Accept optional `initialTranscript` and `initialDuration` parameters
- Pre-fill text controller and duration field if provided
- Show indicator if transcript was auto-generated

### 6. Update ContentViewModel
- Add `createWithTranscript()` method that saves content + transcript in one call
- Or update existing `create()` to accept optional transcript/duration

## Error Handling
- Network timeout (10s)
- No captions available → fallback to manual
- Private/deleted video → show error, allow manual entry
- youtube_explode_dart breaking changes → catch exceptions, fallback gracefully
